# Atividades

## Exercício 1: Adicionar swagger no PokéManager API

1. Adicionem o swagger-autogen na estrutura do projeto PokéManager API.

2. Mapear as rotas em /api/docs:

- GET /api/v1/pokemons
- GET /api/v1/pokemons/:id
- POST /api/v1/pokemons
- PUT /api/v1/pokemons/:id
- DELETE /api/v1/pokemons/:id
- Outras ...

3. Testar a execução dos endpoints diretamente pela interface interativa do Swagger na rota /api/docs.
