# Atividades

## Exercício 1: Adicionar Prisma ao Projeto

1. Rodar os comandos de instalação do Prisma no projeto.

2. Criar a migration da tabela de usuários com npx prisma migrate dev.

3. Testar a rota GET /api/v1/pokemons pelo Swagger.

4. Abrir o Prisma Studio no terminal para visualizar o banco graficamente de forma nativa:

```bash

npx prisma studio

```

Acessar no navegador: http://localhost:5555 e verificar o registro criado!
