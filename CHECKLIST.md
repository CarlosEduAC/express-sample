# Checklist para o PokéManager API

- [ ] Estrutura Clean Architecture: Pastas domain, application, infrastructure e main separadas.
- [ ] Entidades & Repositórios: Entidade validando regras e contrato de repositório em memória funcional.
- [ ] Rotas HTTP & REST: Verbos GET, POST, PUT e DELETE usando status codes adequados (200, 201, 204, 400, 404, 500).
- [ ] Documentação: Swagger rodando sem erros na rota /api/docs.
- [ ] Tratamento de Erros: Middleware errorHandler capturando exceções AppError.
- [ ] GitHub: Repositório público com README.md contendo instruções de execução.
